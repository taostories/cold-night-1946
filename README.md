# 寒夜信使：北平1946

[在线体验](https://taostories.github.io/cold-night-1946/)

以虚构地下交通员经历为线索的网页交互叙事：四章故事、七处调查小游戏、三个主要结局及多种结果变化。人物、案件、线路、密信规则与任务均为创作设定，不作为真实历史个案的复原。

## 游玩

点击“拆开密信”开始；点击“继续”推进对白。小游戏内显示操作说明，手记记录调查证据。浏览器自动保存进度，菜单可以回望章节、查看结局或重新开始。存档保存在当前浏览器中，本地预览的存档不会自动迁移到此线上地址。

音乐在首次点击后开始，右上角可静音。调查与尾声共两首曲目，切换及翻页不会反复从头播放。支持电脑与手机；较长调查界面可向下滚动。

## 部署

纯 HTML、CSS、JavaScript，无需安装依赖或构建。GitHub Pages 从 main 分支根目录发布。下载整个仓库后可双击 index.html 离线运行，或通过静态文件服务器打开。

## 创作与素材

开发使用 AI 辅助编程；场景、人物、小游戏素材与标题由创作者提供，场景与人物为生成式插画，不是历史照片、档案或真实遗址的精确复原。文末尾声含创作说明与精神主题出处。
